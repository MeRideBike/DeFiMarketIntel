# Contributing

DeFi Market Intel is maintained exclusively by its owner, [@MeRideBike](https://github.com/MeRideBike).
External pull requests and code contributions are not accepted and may be
closed without review.

Issues are welcome when they are clear, reproducible, and useful to the
maintainer. Before opening one, search existing issues and include the relevant
version, environment, expected behavior, actual behavior, and safe
reproduction steps.

Please use the appropriate channel:

- Report a reproducible bug or documentation problem through an issue.
- Suggest a feature through an issue, explaining the user need and trade-offs.
- Follow [SECURITY.md](SECURITY.md) for security concerns; do not disclose
  vulnerabilities publicly.

Submitting an issue does not create an obligation to implement it or a
commitment to a delivery timeline.
